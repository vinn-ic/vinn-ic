# PROJETO de TCC
![TCC](https://github.com/3DBMonitoraEdu/TCC)

projeto multiplataforma composto por um agente feito em Go para Windows
(Windows Service) e Linux (systemd daemon), back-end em Express.js com SQLite como banco de dados,
front-end em React.js usando TypeScript.
Projeto voltado para o gerenciamento de computadores em ambientes escolares, com foco em desempenho e
compatibilidade com a infraestrutura da maioria das escolas.
